## Work packages

<a id="r-d06-01"></a>

### R-D06-01 — Research evidence acceptance and contradictions

**Decision to resolve:** What supports intended use, and what remains an auditor sufficiency decision?

**Entry/dependencies:** Source baseline accessible; this task can begin without waiting for unrelated domain research. Dependencies gate affected conclusions/tickets, not all independent reading or drafting.

1. Trace A14/A18 and evidence requests to assertion/entity/period/intended use.
2. Research reliability, external/internal origin, authenticity concerns, conflicting evidence and management representations.
3. Define received, readable, accepted-for-use, disputed, superseded and sufficient-as-concluded states separately.

**Required output:** Evidence-use decision table and contradictory/wrong-period/partial evidence scenarios.

**Validation/contrary case:** File receipt/hash/acceptance cannot independently establish sufficient appropriate audit evidence.

**Close research only when:** full-source/standard evidence, conflicting interpretation, supported boundary, actual owner decision and implementation-ready scenarios are recorded. Use [findings template](../templates/Research_Findings_Template.md). Engineering/practitioner acceptance remains a later separate gate.

### R-D06-02 — Research confirmation control and alternatives

**Decision to resolve:** Who controls selection, sending, replies and nonresponses?

**Entry/dependencies:** R-D06-01 Dependencies gate affected conclusions/tickets, not all independent reading or drafting.

1. Read ISA 505 and source request branches: positive/negative requests, management refusal, reliability doubts and exceptions.
2. Specify request scope, respondent suitability, return channel, response identity and treatment of partial/no replies.
3. Document when alternatives are appropriate and when they cannot replace a necessary positive response; separate live provider effects.

**Required output:** A14/A18 confirmation branch pack, reply/evidence contract and manual dispatch/reply controls.

**Validation/contrary case:** Unauthenticated reply, nonresponse, timing difference, disputed balance and prohibited alternative reach explicit auditor decisions.

**Close research only when:** full-source/standard evidence, conflicting interpretation, supported boundary, actual owner decision and implementation-ready scenarios are recorded. Use [findings template](../templates/Research_Findings_Template.md). Engineering/practitioner acceptance remains a later separate gate.

### R-D06-03 — Research file intake and extraction limits

**Decision to resolve:** Which selected file formats can be safely read and reviewed?

**Entry/dependencies:** R-D03-01 Dependencies gate affected conclusions/tickets, not all independent reading or drafting.

1. Inventory promised PDF/DOCX/XLSX/CSV/image families and current preview/extraction behavior.
2. Research corruption, encrypted/password files, OCR confidence, tables, formulas, hidden content and source/page anchors.
3. Specify original-byte preservation, extraction version, unsupported state, correction/replacement and separate malware-service ownership.

**Required output:** Format support matrix, file identity/readability contract and extraction validation examples.

**Validation/contrary case:** Unreadable/unsupported output is not empty evidence; extracted values are checked against original visible content; scanning is not claimed from parsing.

**Close research only when:** full-source/standard evidence, conflicting interpretation, supported boundary, actual owner decision and implementation-ready scenarios are recorded. Use [findings template](../templates/Research_Findings_Template.md). Engineering/practitioner acceptance remains a later separate gate.

### R-D06-04 — Research scoped sharing and revocation

**Decision to resolve:** What permissions apply to a file and all its representations?

**Entry/dependencies:** R-D02-04, R-D06-03 Dependencies gate affected conclusions/tickets, not all independent reading or drafting.

1. Map grants to original download, preview, thumbnail, extracted text, exports, cached links and replacement versions.
2. Define selected-set semantics, expiry, authority, audit trail and specialist/client return route.
3. Check server-side enforcement and explicit manual sharing controls; document residual copies after permitted download.

**Required output:** Object-level authorization matrix and revocation/expiry threat cases.

**Validation/contrary case:** Revoked recipient is denied through direct endpoints; prior downloads cannot be falsely described as remotely recalled.

**Close research only when:** full-source/standard evidence, conflicting interpretation, supported boundary, actual owner decision and implementation-ready scenarios are recorded. Use [findings template](../templates/Research_Findings_Template.md). Engineering/practitioner acceptance remains a later separate gate.
