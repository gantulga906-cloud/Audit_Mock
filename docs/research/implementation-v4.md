# Audit Mock v4 — workpaper redesign and gap implementation

Start in **Миний ажил**, then open **Ажлын баримтууд**. A workpaper opens in one full page. The company, period, and due date remain visible; the workpaper can be opened in a separate tab. The section index jumps to the relevant part of a long workpaper. Engagement tools are grouped inside **Үйлчлүүлэгчид**. The old **Аудитын урсгал** entry is no longer in the product navigation.

Existing v3 behavior and tests remain. This revision does not close every item from the 136 feature rows, 58 automation minimums or 58 extensions. The previous row-by-row gap audits remain the baseline; the table above lists this revision's implemented slices. The v4 browser storage key migrates existing v3 workspace data once and leaves the old key in place.
