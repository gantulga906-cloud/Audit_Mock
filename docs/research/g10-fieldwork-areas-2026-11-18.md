# G10: actual work across the 22 fieldwork areas

18 November 2026. This implementation follows the 22 original G10 cards and preserves G00–G09. The original source registers, workbooks, handbooks, acceptance list and 25-package/128-task backlog remain unchanged.

## Scope and supported behavior

All 22 areas now have an execution profile and a separately controlled area-work record. The nine added profiles cover intangible assets, long-term receivables, prepayments, accruals, deferred income, intercompany balances, cost of sales, operating expenses and other income/expenses. Existing thirteen area profiles and their original source schemas continue to work. PPE also offers an explicit full-year straight-line calculation; inventory offers the periodic weighted-average calculation alongside its existing movement/count checks.

The new bounded calculations support finite-life full-year straight-line charges and carrying value, contractual receivable roll-forwards with classification left for actual judgment, uniform full-calendar-month allocations, supported service/invoice cut-off, exact reciprocal balances, periodic weighted-average costs, corroborated expenses and supported disposal gains. Exact source editions/methods are selected; malformed, missing, ambiguous, unsupported and overflowing inputs cannot become zero or a favorable result. Monthly profiles check actual calendar start/end and elapsed months. Arithmetic uses integer minor units and explicit half-away-from-zero rounding. Different methods, partial periods, nonuniform performance, uncertain rights, complex financial instruments and other professional questions require their actual manual/specialist work or their separately supported method.

Accepted original CSVs remain linked by exact bytes/hash/version, entity, currency and applicable period. Cases retain exact source rows and measured signed differences. Calculation review is an explicit separate act by the assigned independent reviewer. A new relied-upon source or changed run makes dependent work stale while preserving prior source, run, findings and review history.

## Area work record

In the selected workpaper's analysis section, the G10 panel displays the exact card, original F00788 coordinates, source example and professional boundary. It records the chosen actual source procedure keys from the pinned programme, method and edition, actual method authority/source, and the work performed. Every input requirement needs a current accepted original, source locator and actual work narrative. Area-specific preparer work, reviewer challenges, method boundaries and contradictory evidence are recorded with actual result, evidence and rationale.

Choose manual inspection/reperformance for actual manual work, or explicitly link a current independently reviewed calculation. The latter retains its actual run stamp and all relied-upon originals. Selecting a calculation does not make the source's recognition, rights, classification, impairment, performance, disclosure or legal judgments automatically favorable. Exclusion/N/A requires recorded grounds and remains subject to review.

The actual assigned preparer saves and submits a version. The actual different assigned reviewer returns it with reasons or records an explicit usable/usable-with-matters/additional-work conclusion. Draft revisions, prior returns, exact content digests, sources and reviews remain attributable and recoverable. Changes to the actual source/template/programme, relevant population, assignments or linked calculation require renewed affected work/review. These controls also apply to direct action endpoints. Existing native workpaper preparation, notes, submission and independent review remain separate; a reviewed G10 record does not label an incomplete native paper reviewed.

## G05 handoff, unknown amounts and release

Actual measured exceptions and qualitative/limitation matters have stable keys, original evidence, reasons and a current next owner. Measured differences retain signed direction; the existing gross-exposure interface receives magnitude without losing direction in the origin record. Unquantified matters explicitly retain `unknown`; the existing numeric compatibility slot is not a measured zero. Completion displays their unknown state and requires a separate qualitative assessment. Stable matter keys and idempotent retries do not duplicate the same finding. Existing findings can be explicitly linked only in the same area/engagement with a matching measured exposure; prior G05 decisions are preserved.

The completion workspace receives the actual finding and its source/version lineage. Report readiness requires independent final G05 assessment of the current G10 matter versions, including unquantified matters. A fieldwork review does not resolve a finding, post a correction or approve an opinion. Other native completion, reporting, independent quality and archive requirements remain in force.

Readable selected exports include structured area work, source references, method, actual judgments, matters and independent review. They do not create a new preparation/review signature or hide an unreviewed native workpaper behind the G10 subsection.

## Evidence boundaries and retained work

The G10 matrix exercises normal manual work, actual supported exception handoff, missing input, denied role/self-review and changed-source handling for every card: 110 bounded engineering observations. The manual records are actual application state transitions against fictional accepted sources, distinct from automatic execution of all source procedures. Independent synthetic calculation expectations are checked separately, including an actual-original weighted-cost integration. Restart, exact exports, corrupt originals, private engagement scope and unknown-amount behavior are checked separately.

This evidence does not establish professional whole-variant acceptance, complete native-procedure semantic acceptance, jurisdictional method adoption or all 58 G11 minima. Source-status reports retain those distinctions and the independent acceptance list stays empty. G11 breadth, source-edition/merged-label reconciliation, native-format fidelity, complex method/branch cases and earlier retained requirements remain. The 22 original variants and all their scenarios remain in the source inventory. No invented completion percentage, production rate or generic accounting conclusion is installed.

The running preview, main branch and live database are not updated by this development checkpoint. Verification uses isolated builds and disposable fictional databases. Fixture credentials, runtime databases and browser profiles remain private.

## Official references consulted

On 18 November 2026 the public IFRS Foundation overviews were consulted for the selected calculation boundaries. [IAS 2](https://www.ifrs.org/issued-standards/list-of-standards/ias-2-inventories/) describes inventory cost formulas and the separate lower-value assessment. [IAS 16](https://www.ifrs.org/issued-standards/list-of-standards/ias-16-property-plant-and-equipment/) and [IAS 38](https://www.ifrs.org/issued-standards/list-of-standards/ias-38-intangible-assets/) separate recognition/measurement from a mechanical charge calculation; finite and indefinite lives require different treatment. [IFRS 15](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-15-revenue-from-contracts-with-customers/) ties revenue to actual obligations/performance, so uniform allocation is available only as an explicitly supported profile. These public overviews are not licensed paragraph text, local adoption decisions or a whole-standard compliance assessment.
